# Luxe Legacy Studio

I want you to redesign and build a premium, high-end website inspired by the attached reference HTML, but do NOT make it look like a basic template or a direct copy.

The website should feel like a premium creative/technology brand that someone remembers after visiting it once.

Overall Design Direction

Create a sophisticated Royal Gold / Black / Deep Navy visual identity.

The design should feel:

Premium

Modern

Minimal

Elegant

Expensive

Cinematic

Professional

Highly polished

Memorable

Avoid excessive gold, gradients, glowing effects, glassmorphism, huge rounded cards, generic SaaS layouts, or anything that makes the website look cheap.

Gold should be an accent, not the entire background.

Use a refined palette such as:

Deep black / near-black

Very dark navy

Champagne gold

Metallic gold

Warm off-white

Subtle gray

Use generous whitespace and strong typography.

Typography

Use a premium combination of fonts.

Headings should have a distinctive editorial / luxury feel, while body text should remain highly readable.

Use large typography strategically.

The hero heading should feel visually dominant without taking the entire screen.

Use:

Strong typography hierarchy

Tight heading letter spacing

Comfortable paragraph spacing

Small uppercase labels

Elegant gold micro-text

Clear visual rhythm

Header

Create a premium sticky header.

Desktop:

Minimal logo on the left

Navigation in the center/right

One highlighted CTA

Subtle transparent/blurred background initially

Header becomes slightly more solid while scrolling

Navigation:
Home
About
Services
Work
Process
Contact

Add smooth active-section indication.

Mobile:

Elegant hamburger menu

Full-screen or large slide-in navigation

Smooth open/close animation

Proper touch-friendly spacing

Do not make the header visually heavy.

Hero Section

The hero should be the strongest part of the website.

Create a cinematic premium hero with:

Small gold eyebrow text

Huge headline

Short supporting description

Primary CTA

Secondary CTA

Strong visual composition

Subtle animated background

Use a dark background with carefully controlled gold details.

Add an elegant animated visual element such as:

flowing metallic particles

subtle liquid distortion

moving light rays

abstract 3D golden object

thin orbital lines

premium grain/noise

animated gradient mesh

interactive cursor-following glow

The animation must be subtle and sophisticated.

It should NEVER look like a gaming website.

Add a small scroll indicator at the bottom of the hero.

The first screen should immediately communicate:
"This is a serious premium brand."

Hero Animation

Create a smooth interactive background animation.

The animation should respond slightly to:

Mouse movement

Cursor position

Scrolling

Use GPU-friendly CSS/canvas/WebGL techniques where appropriate.

Keep performance high.

Respect prefers-reduced-motion.

Do not use animations everywhere just because they are possible.

Every animation should have a purpose.

This section should feel more like a luxury brand presentation than a traditional business website.

Disable or simplify this on mobile.

The website should feel fluid rather than animated for the sake of animation.

Images should feel:

Cinematic

Motion Design

Use a consistent motion system.

Fast interactions:
150–250ms

Standard UI transitions:
300–500ms

Large section transitions:
600–1000ms

Use smooth cubic-bezier easing.

Do not animate every element simultaneously.

Create a hierarchy:
Hero = cinematic
Sections = elegant
Buttons = responsive
Portfolio = interactive
Navigation = subtle

Desktop:

Large editorial layouts

Laptop:
1024–1439px

Tablet:

Proper typography scaling

Correct image cropping

Fast loading

Smooth navigation

GPU-friendly effects

Important Design Rule

Do NOT copy the reference website literally.

Use its overall content structure and interaction ideas as inspiration, but create a significantly more premium visual identity.

The final result should feel like a website designed by a top-tier branding agency.

Think:

Luxury brand + modern technology + editorial design + cinematic motion.

Not:

Template + cards + gradients + generic SaaS.

Final Quality Check

Before considering the website complete, check:

Does the first screen immediately feel premium?

Does the website have a strong visual identity?

Is gold being used as an accent rather than everywhere?

Does typography look expensive and intentional?

Are animations smooth and purposeful?

Does the portfolio feel visually impressive?

Does the website still look good without animations?

Does mobile feel intentionally designed?

Are there any generic-looking cards or sections that can be improved?

Does the whole website feel like one consistent brand?

If any section feels generic, redesign that section instead of simply adding more effects.

The final website should feel premium, memorable, elegant, modern, technically polished, and visually distinctive.
